How it works

From screen to shared in seconds

Snipit waits quietly in your system tray. When you need it, one key gets you from “look at this” to a clear, annotated image.

1

Press PrtSc

The screen freezes on every monitor. Drag a region or click a window — the magnifier loupe helps you land on the exact pixel.

2

Mark it up

The editor opens with your capture. Point with arrows, number the steps, add a callout and blur anything private.

3

Copy & paste

Hit Ctrl+C and drop it into Slack, Teams, email or a ticket. It’s also saved to your gallery automatically.

Features

Everything you need, nothing in the way

A fast native app built with Rust and Tauri — small download, low memory, starts instantly.

Region & window capture

Freeze-frame overlay with a magnifier loupe and live size readout. Hover to highlight a window, click to grab it.

Multi-monitor aware

Works across all your displays, including mixed DPI setups. Shift+PrtSc grabs the current monitor in one go.

13 annotation tools

Arrows, shapes, pen, highlighter, text, callouts and auto-numbered steps — each one a single keystroke away.

Blur & pixelate

Hide emails, tokens and faces before you share. Drag over the sensitive part and it’s gone.

Non-destructive editing

Crop is undoable, and your original capture is never overwritten. Export is pixel-exact at the original size.

Zoom & pan

Ctrl+scroll to zoom, hold Space or middle-drag to pan. Fit to window or jump to 100%.

Clipboard first

Copy the annotated result with one shortcut — or paste any image from the clipboard and annotate that instead.

Auto-saved gallery

Every capture lands as a PNG in Pictures\Snipit. Browse, reopen, copy or delete from the built-in gallery.

Always up to date

Signed automatic updates from GitHub Releases. Per-user install — no admin prompt, no IT ticket.

Keyboard first

Stays out of your way until you need it

Snipit starts with Windows and lives in the tray. Every shortcut can be rebound in Settings.

  • Rebindable hotkeys — if Snagit, ShareX or Snipping Tool already owns PrtSc, Snipit tells you and lets you pick another key.
  • Your choice after capture — open the editor (default) or send straight to the clipboard.
  • Scriptable — snipit --capture and snipit --capture-fullscreen for launchers and macros.

FAQ

Questions

Is Snipit really free?

Yes. It’s open source under the MIT license — no trial, no watermark, no account.

Windows says “Windows protected your PC”.

The installer isn’t code-signed yet, so SmartScreen warns about it. Click More info → Run anyway. Code signing is on the roadmap.

Pressing PrtSc doesn’t open Snipit.

Windows or another tool has claimed the key. Turn off Settings → Accessibility → Keyboard → Use the Print screen key to open screen capture, or close the other screenshot tool — or simply choose a different shortcut in Snipit’s Settings. Snipit shows a notice when this happens.

Where are my captures saved?

In Pictures\Snipit as PNG files. Editing never overwrites the original capture.

Does it need admin rights?

No. The setup installs for your user only and adds WebView2 if it’s missing. An .msi is also provided for managed / IT deployments.

What about macOS and Linux?

Windows comes first. Snipit is built on Tauri, so macOS and Linux builds are planned.
